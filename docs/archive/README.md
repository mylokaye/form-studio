# Historical examples

The original Lead/Contact exports, visual CSS experiment, and standalone smoke demo have been moved here unchanged. They are archival comparisons, not active starting points or deployment templates. Lead exports include invalid consent placeholders and nonportable identifiers; older styles include HIP CAPTCHA selectors. The old demo intercepts submission and displays simulated success.

The active paired regression fixtures and separate preview harness are documented in [the repository README](../../README.md). Always style the user's own Dynamics export rather than copying one of these examples.
